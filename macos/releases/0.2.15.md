- Native macOS editor with Continuous, Pages, and Draft views.
- Draft font, line-spacing, appearance, and zoom preferences.
- Saved documents and their editor/window state can resume after relaunch,
  following macOS's window-restoration preference.
- Untouched startup documents close when an existing file opens successfully.
- Native Copy/Cut integration and more visible search matches.
- Ribbon bookmark app icon.

This is an editor preview. Apple Silicon builds, VoiceOver validation, and
large-document performance validation remain outstanding. Unsaved edits use
Save/Discard/Cancel; crash-recovery copies are available separately.
