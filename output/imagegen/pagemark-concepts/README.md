# Pagemark icon concepts

Two exploratory macOS icon directions, generated using the imagegen skill's
approved CLI fallback with `gpt-image-2`, high quality, 1024 × 1024 PNG output.
The exact prompts are preserved in [prompts.jsonl](prompts.jsonl).

1. **Marked page** — an ivory sheet, three dark text strokes, and a vermilion
   margin mark on an ink-blue rounded square.
2. **Overstruck P** — a heavy ivory typewriter P with a subtly offset second
   impression on an ink-blue rounded square.

These are concept previews with opaque backgrounds, not production icon bundles.
